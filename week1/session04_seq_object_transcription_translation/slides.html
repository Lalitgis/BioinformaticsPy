Strands and reverse complement

DNA is double-stranded and antiparallel. A gene can be encoded on either strand. Biopython always stores what you give it, and computes the other strand on demand:

from Bio.Seq import Seq
gene = Seq("ATGGCTAGCTAG")
print(gene.complement())          # base-by-base complement, same direction
print(gene.reverse_complement())  # what's actually on the opposite strand, 5'->3'
When you download a plant gene from NCBI and it's annotated on the "minus strand", you must reverse-complement it before translating — otherwise you'll get nonsense protein.

Transcription: DNA → mRNA

coding_dna = Seq("ATGGCTAGCTAG")
mrna = coding_dna.transcribe()
print(mrna)   # AUGGCUAGCUAG  (T -> U, that's it)

Transcription (in Biopython's simplified model) is literally just T→U substitution of the coding/sense strand — because the coding strand already has the same sequence as the mRNA (except U instead of T). The template strand is what RNA polymerase actually reads, but Biopython works with the coding strand by convention since that's what's usually stored in databases.

Translation: mRNA/DNA → Protein

coding_dna = Seq("ATGGCTAGCTAG")
protein = coding_dna.translate()
print(protein)              # M A S *      (* = stop codon)
print(coding_dna.translate(to_stop=True))   # M A S   (stop symbol dropped)

Biopython can translate DNA directly (skipping the mRNA intermediate) — the genetic code table is the same. Use to_stop=True when you just want the protein without a trailing *.

Reading frame matters! Translation reads codons (groups of 3) starting exactly where you tell it to. If your sequence isn't trimmed to start at the true ATG, you'll get garbage. Real CDS sequences from GenBank are already frame-corrected for you.

Putting it together on a real plant gene

from Bio import SeqIO
record = SeqIO.read("AT5G10140_FLC_synthetic_cds.fasta", "fasta")
protein = record.seq.translate(to_stop=True)
print("Protein length:", len(protein))
print(protein)
FLC encodes a MADS-box transcription factor — a family of proteins with a highly conserved DNA-binding domain found across all flowering plants, controlling flower development, fruit ripening, and (for FLC specifically) blocking flowering until winter cold is sensed (vernalization). Translating it turns an abstract DNA string into a molecule with real biological identity.
