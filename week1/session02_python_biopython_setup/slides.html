Python refresher — just what we need

Strings (a DNA sequence IS a string)

s = "ATGCGTACG"
print(len(s))          # 9
print(s[0:3])           # "ATG"  (a codon)
print(s.count("G"))     # count of G bases
print(s.replace("T","U"))  # crude RNA

Dictionaries (great for codon tables, counts)

counts = {"A":0,"C":0,"G":0,"T":0}
for base in s:
    counts[base] += 1
print(counts)

Loops & functions

def gc_content(seq):
    g = seq.count("G")
    c = seq.count("C")
    return (g + c) / len(seq) * 100

print(gc_content(s))

Reading a file

with open("myfile.txt") as f:
    for line in f:
        print(line.strip())

Your first Biopython script

The Bio.Seq.Seq object behaves like a string, but knows biology (it can reverse-complement, transcribe, translate — we'll use all of that from Session 4 onward).

from Bio.Seq import Seq

my_seq = Seq("ATGGCTAGCTAG")
print(my_seq)
print("Length:", len(my_seq))
print("Reverse complement:", my_seq.reverse_complement())
Today's dataset: data/AT5G10140_FLC_synthetic_cds.fasta — a teaching sequence modeled on Arabidopsis FLOWERING LOCUS C (FLC), the master repressor of flowering that gets epigenetically silenced by cold (vernalization). We'll use this same gene repeatedly through the course.
