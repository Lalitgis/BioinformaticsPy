GC content — a quick genomic fingerprint

from Bio.SeqUtils import gc_fraction
gc = gc_fraction(my_seq) * 100
print(f"{gc:.1f}% GC")
GC content varies a lot across plant genomes and even within one genome: coding regions tend to be more GC-rich than introns/intergenic DNA; grasses (rice, maize, wheat) generally run GC-richer than dicots like Arabidopsis. GC content also affects PCR — GC-rich templates need higher annealing/denaturation temperatures.

Molecular weight & melting temperature (Tm) — primer-design building blocks

from Bio.SeqUtils import molecular_weight
from Bio.SeqUtils import MeltingTemp as mt

mw = molecular_weight(my_seq)
tm = mt.Tm_Wallace(my_seq)   # simple Wallace-rule estimate, good for short primers
print(f"MW: {mw:.0f} g/mol   Tm: {tm:.1f} °C")

Real primer-design software uses more sophisticated Tm formulas (nearest-neighbor thermodynamics), but the Wallace rule (Tm = 2°C × (A+T) + 4°C × (G+C)) is a good teaching approximation and is still used for quick short-primer checks in the lab.

Codon usage bias — every species has a 'accent'

Multiple codons can encode the same amino acid (the genetic code is degenerate), but organisms don't use synonymous codons equally — this is codon usage bias, driven by tRNA abundance.

def codon_usage(seq_str):
    usage = {}
    for i in range(0, len(seq_str) - 2, 3):
        codon = seq_str[i:i+3]
        usage[codon] = usage.get(codon, 0) + 1
    return usage
This matters practically in plant biotechnology: if you want to express a bacterial gene (e.g., Bt toxin for pest resistance) in a plant, you often need to codon-optimize it to match the host plant's preferred codons, or expression will be poor.

Comparing two genes/species side by side

Today's exercise compares GC content and codon usage between the Arabidopsis and maize DREB2A-like orthologs — a small, hands-on taste of exactly the kind of comparative analysis used before doing codon-optimization for plant genetic engineering.

Tip for the classroom: have students predict, before running any code, which species they expect to be more GC-rich — grasses (rice/maize) or Arabidopsis — then check it computationally. It's a great "hypothesis then test" moment.
