The three formats you'll see constantly

FormatExtensionContainsUsed for
FASTA.fasta/.fa/.fnaheader line (>id description) + raw sequence Simple sequence storage/exchange — genes, genomes, proteins
GenBank.gb/.gbksequence plus rich annotation: genes, CDS, exons, source organism Full records downloaded from NCBI
FASTQ.fastq/.fqsequence + per-base quality scores Raw reads straight off a sequencing machine (we touch this in Week 4)
FASTA is the "just the sequence" format. GenBank is the "sequence + full annotation" format. Think of FASTA as a photo, GenBank as the photo with captions on every part of it.

Reading with Bio.SeqIO

SeqIO.read() — exactly one record expected (errors otherwise).
SeqIO.parse() — an iterator over any number of records (use in a for loop).

from Bio import SeqIO

# Exactly one record
record = SeqIO.read("single_gene.fasta", "fasta")

# Many records — iterate!
for record in SeqIO.parse("gene_family.fasta", "fasta"):
    print(record.id, len(record.seq))
Today's multi-record file: DREB2A_plant_orthologs.fasta — five synthetic-but-realistic DREB2A-type orthologs (Arabidopsis, rice, maize, soybean, tomato). DREB2A is a transcription factor central to drought tolerance across crops — we'll align and build a tree from these same 5 sequences later in the course.

A SeqRecord is more than a sequence

Every record from SeqIO is a SeqRecord object bundling the sequence with metadata:

record.id            # accession/identifier, e.g. "Oryza_sativa_DREB2A_like"
record.description   # full header line
record.seq           # the Seq object itself
record.features      # list of annotated regions (GenBank only, empty for FASTA)
record.annotations    # dict of metadata (organism, molecule_type, ...) (GenBank only)

Open data/FLC_teaching_record.gb in a text editor once, just to see what a real GenBank flat file looks like before we parse it with code — it demystifies the format immediately.

Writing / filtering sequences out to a new file

from Bio import SeqIO

records = list(SeqIO.parse("DREB2A_plant_orthologs.fasta", "fasta"))

# keep only sequences longer than 400 bp, as an example filter
long_ones = [r for r in records if len(r.seq) > 400]

SeqIO.write(long_ones, "filtered_output.fasta", "fasta")
print(f"Wrote {len(long_ones)} of {len(records)} records")
This read → filter/transform → write pattern is the backbone of almost every real bioinformatics script you will ever write. Learn it well today.
