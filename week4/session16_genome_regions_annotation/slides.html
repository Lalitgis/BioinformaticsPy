From one gene to a whole region

So far we've analyzed single genes in isolation. Real genome annotation works on long, multi-megabase scaffolds/chromosomes containing many genes, packed with repeats, and only ~1-5% coding in a genome like maize (vs. ~25% coding in the much more compact Arabidopsis genome).

This is why genome annotation — the process of computationally predicting where genes are in raw assembled DNA — is genuinely hard, and why crop genome annotation projects (rice, maize, wheat, tomato) are major multi-year international collaborations.

GFF3 — the standard genome annotation format

##gff-version 3
Chr1  maker  gene  1000  2500  .  +  .  ID=gene001;Name=FLC
Chr1  maker  mRNA  1000  2500  .  +  .  ID=mRNA001;Parent=gene001
Chr1  maker  CDS   1050  2450  .  +  0  ID=cds001;Parent=mRNA001

GFF3 (General Feature Format v3) is a plain tab-separated format: each line is one feature, with a hierarchical ID/Parent relationship linking genes → mRNAs → exons/CDS. It's the standard hand-off format between an annotation pipeline and downstream analysis tools.

def parse_gff3_line(line):
    fields = line.strip().split("\t")
    chrom, source, ftype, start, end, score, strand, phase, attrs = fields
    attr_dict = dict(pair.split("=") for pair in attrs.split(";") if "=" in pair)
    return {"chrom": chrom, "type": ftype, "start": int(start), "end": int(end),
            "strand": strand, "attrs": attr_dict}

Gene density & intergenic distance

def gene_density(gene_list, region_length):
    total_gene_bp = sum(g["end"] - g["start"] for g in gene_list)
    return total_gene_bp / region_length * 100

def intergenic_distances(gene_list):
    sorted_genes = sorted(gene_list, key=lambda g: g["start"])
    return [sorted_genes[i+1]["start"] - sorted_genes[i]["end"]
            for i in range(len(sorted_genes)-1)]
Compact genomes (Arabidopsis) tend to have short intergenic distances and high gene density; repeat-rich genomes (maize, wheat) have long stretches of transposable elements between genes — visualizing intergenic distance distributions is a quick way to characterize a newly assembled genome region before deep analysis.
