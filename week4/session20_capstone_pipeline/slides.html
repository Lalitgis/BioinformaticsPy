The capstone brief

Students (individually or in pairs) build one end-to-end script/notebook answering a single research question, using only tools from this course. Suggested question:

"Is the drought-response transcription factor DREB2A evolutionarily conserved across plant lineages, and is its expression consistent with a real drought-response role?"

This requires touching nearly every session: sequence loading (S3), alignment (S8-9), phylogenetics (S11-12), motif/protein analysis (S14), and expression data (S17-18) — a genuine synthesis exercise.

The pipeline skeleton (fill in from earlier sessions)

# 1. Load & inspect the DREB2A ortholog sequences (Session 3-5)
# 2. Multiple sequence alignment (Session 9)
# 3. Build a phylogenetic tree and check it against known plant taxonomy (Session 11-12)
# 4. Translate each ortholog's DNA and confirm the protein has intact reading frames (Session 4)
# 5. Report percent identity across all pairs (Session 8)
# 6. Cross-reference with the RNA-seq drought expression data — is DREB2A really upregulated? (Session 18)
# 7. Write a 3-5 sentence conclusion in plain English, citing your actual numbers
Every one of these steps is code students have already written in a prior session — the capstone's whole point is realizing they can now assemble a real workflow from parts they've mastered, not learning anything brand new.

What a finished mini-report should look like

Example structure (aim for ~half a page):
  1. Question: one sentence.
  2. Methods: 2-3 sentences naming the data and tools used (sequences, alignment, tree method).
  3. Results: the key numbers — e.g., "DREB2A orthologs show 78-95% pairwise DNA identity across 5 species; the resulting NJ tree correctly separates monocots (rice, maize) from dicots (Arabidopsis, soybean, tomato); DREB2A shows a log2 fold-change of +2.2 under drought stress."
  4. Conclusion: what this suggests biologically, and one honest limitation of the analysis (e.g., "synthetic teaching data, small sample size, no statistical test applied to expression change").

For you, the tutor — running this course going forward

  • Pacing: Weeks 1-2 are usually comfortable at 2h/session; Weeks 3-4 (phylogenetics, stats-heavy sessions) often need the full 2 hours plus follow-up office hours for slower students — build in slack, don't rush the tree-building or GWAS sessions.
  • Common struggles: off-by-one errors in sequence slicing (Session 4), confusing SeqIO.read vs .parse (Session 3), and forgetting str() conversions when mixing Seq objects with regex/pandas (Sessions 14, 15).
  • Where to go next: real NCBI Entrez fetching (Session 6, with real internet), local BLAST against a full reference genome, RNA-seq from raw FASTQ (Session 18 extension), and a real statistics course module (R + DESeq2, or PyDESeq2) once students want to move beyond fold-change thresholds.
  • Re-teaching: every session folder is self-contained (slides.html, code_along.py, exercise.md) — reuse this course indefinitely, and feel free to swap in your own local crop species/datasets once your students want something specific to their region's agriculture.
