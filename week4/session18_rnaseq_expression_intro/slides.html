The RNA-seq pipeline, bird's-eye view

  1. Extract RNA from tissue (e.g., Arabidopsis leaves, control vs. drought-stressed).
  2. Sequence it (millions of short reads, FASTQ files) — this is real "big data" territory.
  3. Align reads to a reference genome/transcriptome (tools like HISAT2, STAR — beyond this course's scope, but conceptually important).
  4. Count how many reads land on each gene → a gene × sample count matrix.
  5. Normalize, then statistically test for differential expression between conditions.
Today we start at step 4 — you're handed a realistic count matrix (arabidopsis_drought_rnaseq_counts.csv) and do steps 4-5, which is exactly where most biologists (not doing the sequencing/alignment themselves) actually start working with RNA-seq data.

Loading & normalizing counts with pandas

import pandas as pd

counts = pd.read_csv("arabidopsis_drought_rnaseq_counts.csv", index_col="gene_id")
print(counts.head())

# CPM: Counts Per Million - normalizes for differing total sequencing depth per sample
cpm = counts.div(counts.sum(axis=0), axis=1) * 1e6
print(cpm.head())
Raw counts can't be compared directly between samples if they had different total sequencing depth (one sample simply got more reads than another) — CPM normalization (or more sophisticated methods like TMM/DESeq2's median-of-ratios, used in real published studies) corrects for this before any comparison is meaningful.

Fold-change: the simplest differential expression signal

control_cols = ["Control_rep1", "Control_rep2", "Control_rep3"]
drought_cols = ["Drought_rep1", "Drought_rep2", "Drought_rep3"]

mean_control = cpm[control_cols].mean(axis=1)
mean_drought = cpm[drought_cols].mean(axis=1)

import numpy as np
log2fc = np.log2((mean_drought + 1) / (mean_control + 1))   # +1 pseudocount avoids log(0)
results = pd.DataFrame({"mean_control": mean_control, "mean_drought": mean_drought, "log2FC": log2fc})
results_sorted = results.sort_values("log2FC", ascending=False)
print(results_sorted)
Expect DREB2A, RD29A/B, and other drought-response genes at the top (strongly upregulated), and photosynthesis genes (RBCS1A, CAB1, PSBA) at the bottom (downregulated) — plants actively down-regulate photosynthetic machinery under severe stress to conserve resources.

Visualizing results

import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt

top_genes = results_sorted.head(8)
plt.figure(figsize=(8, 4))
plt.barh(top_genes.index, top_genes["log2FC"])
plt.xlabel("log2 fold change (Drought vs Control)")
plt.title("Top upregulated genes under drought stress")
plt.tight_layout()
plt.savefig("top_drought_genes.png", dpi=150)
Real studies use a proper statistical test (e.g., DESeq2 or edgeR in R, or PyDESeq2 in Python) combining fold-change AND a p-value (often visualized together in a volcano plot). Today's exercise builds a simplified volcano-style plot using fold-change and variability across replicates as a stand-in for statistical significance.
