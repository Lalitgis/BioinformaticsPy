Rooted vs. unrooted trees, and why the root matters

The Neighbor-Joining algorithm from Session 11 produces an unrooted tree by default — it tells you the pattern of relationships, but not "which direction is ancestral." To get a rooted tree with a real evolutionary direction, you need an outgroup: a sequence known (from outside evidence) to have branched off before all the others.

tree.root_with_outgroup({"name": "Nicotiana_tabacum_tobacco"})
For our 5 Solanaceae species, tobacco (genus Nicotiana) is a reasonable outgroup relative to the tomato/potato/pepper/petunia group, since taxonomically it sits somewhat more distantly within the family — a good discussion point on how you'd actually choose an outgroup in a real study (usually the next-closest well-characterized relative outside your group of interest).

Drawing a real figure with matplotlib

import matplotlib
matplotlib.use("Agg")   # so it works without a display, e.g. in a script/server
import matplotlib.pyplot as plt
from Bio import Phylo

fig, ax = plt.subplots(figsize=(8, 4))
Phylo.draw(tree, axes=ax, do_show=False)
plt.tight_layout()
plt.savefig("solanaceae_tree.png", dpi=150)
Always save a static image (.png/.pdf) alongside your analysis code — a tree figure with no way to reproduce it is far less useful than a script + saved Newick file + generated figure, all under version control.

Branch lengths & support values — what they mean (and don't)

  • Branch length — usually proportional to the amount of sequence change (substitutions per site) along that branch, not necessarily calendar time (unless the tree is time-calibrated with a molecular clock and fossil/known-divergence calibration points).
  • Bootstrap support (not computed by our simple pipeline, but you'll see it constantly in real papers, usually shown as a % at internal nodes) — measures how consistently that grouping appears when the alignment is randomly resampled many times; it reflects confidence in the topology, not correctness of the underlying biology.
A tree with 100% bootstrap support can still be biologically "wrong" if there's a systematic problem (bad alignment, wrong evolutionary model, gene tree ≠ species tree due to hybridization or incomplete lineage sorting — both common in crop plants!).

Reading a real breeding-relevant tree

Real-world plant breeding use case: when breeders want to introduce a disease-resistance gene from a wild relative into a cultivated crop (e.g., wild tomato species into cultivated tomato), a phylogenetic tree tells them which wild relatives are close enough to cross-breed conventionally, versus which are so distant they'd need advanced techniques (embryo rescue, genetic engineering) to bridge the gap.
