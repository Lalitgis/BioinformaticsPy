What a phylogenetic tree tells you

A phylogenetic tree is a hypothesis about evolutionary relationships, built from how similar/different sequences are. Species (or genes) that share a more recent common ancestor are placed closer together, joined at a more recent internal node ("branch point").

DNA barcoding: plant taxonomists commonly use short, standardized, variable-but-not-too-variable regions — like the plastid gene matK or rbcL — to quickly build trees and identify species, especially useful when morphology alone is ambiguous (e.g. distinguishing crop wild relatives).

Step 1: MSA → distance matrix

from Bio import AlignIO
from Bio.Phylo.TreeConstruction import DistanceCalculator

alignment = AlignIO.read("matk_aligned.fasta", "fasta")
calculator = DistanceCalculator("identity")   # simplest metric: fraction of differing sites
dist_matrix = calculator.get_distance(alignment)
print(dist_matrix)

The "identity" model just counts mismatches; more sophisticated models ("blastn", "trans", amino-acid substitution matrices) correct for the fact that multiple mutations can hit the same site over long evolutionary time (multiple substitutions "hidden" behind one observed difference) — worth mentioning conceptually even if we keep it simple today.

Step 2: distance matrix → tree (two algorithms)

UPGMA

Assumes a constant molecular clock (equal mutation rate in every lineage). Simple, always produces an ultrametric (equal root-to-tip distance) tree — but that assumption is often biologically wrong.

constructor = DistanceTreeConstructor()
tree = constructor.upgma(dist_matrix)

Neighbor-Joining (NJ)

Does not assume a constant clock — generally preferred in real work for that reason.

tree = constructor.nj(dist_matrix)

Building & viewing your first real tree

from Bio import Phylo
Phylo.draw_ascii(tree)          # quick terminal-friendly view
Phylo.write(tree, "tree.nwk", "newick")   # save in the universal Newick tree format
Today's tree uses 5 real Solanaceae (nightshade family) crops: tomato, potato, pepper, petunia, and tobacco. Before running the code, ask students to predict the tree shape from what they know: tomato and potato are both in genus Solanum — do you expect them to group together? (They should!) This "predict, then verify" habit builds real scientific intuition.
