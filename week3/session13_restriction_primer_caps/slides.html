What is a CAPS marker, and why breeders love them

A CAPS marker (Cleaved Amplified Polymorphic Sequence) exploits a SNP that happens to fall inside a restriction enzyme's recognition site. PCR-amplify the region, digest with that enzyme, and run on a gel: one allele gets cut (multiple bands), the other doesn't (one uncut band). No sequencing needed — just PCR + digestion + gel, making it cheap enough for screening thousands of breeding plants.

This is a real, still widely used tool in plant breeding programs for marker-assisted selection (MAS) — e.g., confirming a seedling inherited a disease-resistance allele before it ever flowers, saving years of field growing time.

Finding restriction sites with Biopython

from Bio.Restriction import EcoRI
from Bio.Seq import Seq

seq = Seq("GGGGGAATTCGGGG")
sites = EcoRI.search(seq)
print(sites)   # 1-based positions right after the cut point

Or search with many enzymes at once using an Analysis or a RestrictionBatch:

from Bio.Restriction import RestrictionBatch
rb = RestrictionBatch(["EcoRI", "BamHI", "HindIII"])
result = rb.search(seq)
for enzyme, positions in result.items():
    print(enzyme, positions)

Simulating the CAPS marker gel result

from Bio import SeqIO
from Bio.Restriction import EcoRI

wt, mutant = list(SeqIO.parse("FLC_CAPS_marker_alleles.fasta", "fasta"))

for allele in (wt, mutant):
    cuts = EcoRI.search(allele.seq)
    fragments = len(cuts) + 1
    print(f"{allele.id}: {len(cuts)} EcoRI site(s) -> {fragments} fragment(s) on the gel")
Today's dataset is a pair of synthetic FLC alleles engineered so a single SNP destroys one EcoRI site in the "mutant" allele. Because the mutant loses a cut site, it produces one fewer fragment than the wild-type on a gel — a different, reproducible band pattern between alleles. This difference-in-band-count is the exact logic used to genotype real segregating breeding populations.

PCR primer design basics

from Bio.SeqUtils import MeltingTemp as mt

def check_primer(primer_seq):
    tm = mt.Tm_Wallace(primer_seq)
    gc = (primer_seq.count("G") + primer_seq.count("C")) / len(primer_seq) * 100
    return {"length": len(primer_seq), "Tm": round(tm, 1), "GC%": round(gc, 1)}

forward = "CGCGGAATATCTTTTGTAAG"
print(check_primer(forward))
Good primer rules of thumb: 18-25 bp long, 40-60% GC, Tm between 50-65°C, and forward & reverse primer Tm within ~2-3°C of each other (so they anneal at the same PCR temperature).
