VCF — the standard format for genetic variants

##fileformat=VCFv4.2
#CHROM  POS   ID    REF  ALT  QUAL  FILTER  INFO         FORMAT  Sample1  Sample2 ...
Chr1    1234  rs1   A    G    99    PASS    GENE=SD1     GT      0/0      0/1 ...
  • REF/ALT — the reference base and the alternate (variant) base.
  • GT (genotype) — 0/0 homozygous reference, 0/1 heterozygous, 1/1 homozygous alternate (for a diploid, unphased genotype).
  • Modern crop breeding programs and germplasm banks (e.g., the 3,000 Rice Genomes Project) store millions of SNPs across thousands of accessions in exactly this format.

Parsing VCF without extra libraries

samples = None
records = []
with open("rice_panel.vcf") as f:
    for line in f:
        if line.startswith("##"):
            continue
        if line.startswith("#CHROM"):
            samples = line.strip().split("\t")[9:]
            continue
        fields = line.strip().split("\t")
        chrom, pos, snp_id, ref, alt = fields[:5]
        genotypes = fields[9:]
        records.append({"chrom": chrom, "pos": int(pos), "id": snp_id,
                         "ref": ref, "alt": alt, "genotypes": dict(zip(samples, genotypes))})
You could use a library like pysam or cyvcf2 for large real files, but understanding the raw format by parsing it yourself first builds real intuition — and this simple parser handles files up to a few hundred thousand lines just fine.

Allele frequency — the basic unit of population genetics

def allele_frequency(genotypes):
    alt_count, total = 0, 0
    for gt in genotypes.values():
        alleles = gt.replace("|", "/").split("/")
        alt_count += alleles.count("1")
        total += len(alleles)
    return alt_count / total

for rec in records[:5]:
    freq = allele_frequency(rec["genotypes"])
    print(f"{rec['id']} (pos {rec['pos']}): ALT allele frequency = {freq:.2f}")
A SNP near the rice Sub1A gene (submergence tolerance) at high frequency in a set of flood-prone-region varieties, but low/absent in upland varieties, is exactly the kind of signal breeders look for when hunting adaptive alleles.

A first taste of population structure

If a SNP shows dramatically different allele frequencies between two subsets of your samples, that's evidence of population structure — the samples aren't one randomly-mating group, but at least two genetically distinguishable subpopulations (e.g., indica vs. japonica rice subspecies).

group_a = samples[:5]
group_b = samples[5:]

for rec in records:
    freq_a = allele_frequency({s: rec["genotypes"][s] for s in group_a})
    freq_b = allele_frequency({s: rec["genotypes"][s] for s in group_b})
    if abs(freq_a - freq_b) > 0.5:
        print(f"{rec['id']}: strong frequency difference! group A={freq_a:.2f} group B={freq_b:.2f}")
