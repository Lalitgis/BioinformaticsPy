Datasets used this session: 📁 DREB2A_plant_orthologs.fasta

Why not just do pairwise alignments for everything?

With 5 sequences you'd need 10 separate pairwise alignments, and they wouldn't even agree with each other on where gaps go. A multiple sequence alignment (MSA) aligns all sequences together in one consistent set of columns — essential before building a phylogenetic tree (Session 11) or scanning for conserved motifs (Session 14).

Real MSA algorithms (Clustal Omega, MUSCLE, MAFFT) use a progressive strategy: build a rough guide tree from pairwise distances, then align the most similar sequences first and progressively add more distant ones.

Installing an aligner (one-time setup)

# Ubuntu/Debian
sudo apt-get install clustalo

# macOS with Homebrew
brew install clustal-omega

# Conda (any OS)
conda install -c bioconda clustalo

Biopython no longer ships built-in wrapper classes for external aligners (they were removed from recent versions) — the modern approach is simply to call the command-line tool with Python's subprocess module, which is what we do today.

Running Clustal Omega from Python

import subprocess

subprocess.run([
    "clustalo",
    "-i", "DREB2A_plant_orthologs.fasta",
    "-o", "dreb2a_aligned.fasta",
    "--outfmt=fasta",
    "--force",
], check=True)

Then load the result with Biopython's alignment reader (note: AlignIO, different from SeqIO, because now every sequence in the file is the same length, padded with - gap characters):

from Bio import AlignIO
alignment = AlignIO.read("dreb2a_aligned.fasta", "fasta")
print(alignment)
print("Alignment length (with gaps):", alignment.get_alignment_length())

Reading an MSA: conserved vs. variable columns

for col in range(alignment.get_alignment_length()):
    column = alignment[:, col]     # every sequence's base at this column
    if len(set(column)) == 1:
        pass  # fully conserved column
Columns that are identical across all species despite ~150 million years of divergence (dicots vs. grasses) are very likely under strong purifying selection — often the DNA-binding domain or catalytic core of the protein. Today's exercise has students find and report the single most conserved stretch in the DREB2A alignment — a real, if simplified, taste of comparative genomics used to prioritize candidate functional residues.
