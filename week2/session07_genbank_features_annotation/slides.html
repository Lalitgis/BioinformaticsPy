Anatomy of a GenBank feature

Each entry in record.features is a SeqFeature with:

  • .type — e.g. "gene", "CDS", "5'UTR", "exon"
  • .location — a FeatureLocation (start, end, strand)
  • .qualifiers — a dict of extra info: gene name, product, sometimes even the translation itself pre-computed by NCBI
for feat in record.features:
    print(feat.type, feat.location, feat.qualifiers.get("gene"))

Extracting the sequence a feature actually covers

for feat in record.features:
    if feat.type == "CDS":
        cds_seq = feat.extract(record.seq)
        print("CDS length:", len(cds_seq))
        print("Translation:", cds_seq.translate(to_stop=True))
Notice we never manually sliced record.seq[start:end] — feature.extract() handles strand direction (reverse-complementing automatically for minus-strand features) and even joins multiple exons together for spliced genes. Always prefer .extract() over manual slicing once features are involved.

Real plant gene structure: UTRs, CDS, introns

Typical eukaryotic gene layout

5' --[5'UTR]--[exon1]--[intron]--[exon2]--[3'UTR]-- 3'
              \________ CDS (spliced) ________/

Today's record

FLC_teaching_record.gb models a single-exon simplified gene (5'UTR + CDS + 3'UTR) so the extraction logic is crystal clear before we deal with real multi-exon genes later.

Real Arabidopsis FLC actually has 6 exons and 5 introns spanning ~4.3 kb of genomic DNA, but the spliced mRNA/CDS is much shorter — a great discussion point: genomic coordinates vs. mRNA coordinates are NOT the same numbering, and this trips up beginners constantly.

Building a one-gene annotation report

def summarize_record(record):
    print(f"ID: {record.id}")
    print(f"Organism: {record.annotations.get('organism')}")
    print(f"Total length: {len(record.seq)} bp")
    for feat in record.features:
        length = len(feat.location)
        print(f"  {feat.type:10s} {feat.location}  ({length} bp)")

This kind of little report-generating function is something you'll write in some form in almost every future session — it's worth having students build muscle memory for it now.
