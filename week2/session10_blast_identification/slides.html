What BLAST actually does

BLAST (Basic Local Alignment Search Tool) takes a query sequence and rapidly searches a (potentially huge) database for statistically significant local alignments — "what in this haystack looks like my needle?" It trades a little alignment optimality for enormous speed via a clever seed-and- extend heuristic, which is why it can search all of GenBank in seconds.

Key output columns: identity, E-value, bit score

  • % identity — how similar the aligned region is.
  • E-value — the number of hits this good you'd expect by chance alone in a database this size. Lower is better; 1e-50 is a much stronger hit than 0.02.
  • Bit score — a normalized alignment quality score, comparable across different searches.
A common beginner mistake: judging a hit only by % identity. A short 10 bp 100%-identical match is meaningless (E-value will be terrible); a 400 bp match at 85% identity with E-value 1e-100 is a real, confident hit.

Local BLAST (works fully offline, today's exercise)

# One-time: build a searchable database from a FASTA file
makeblastdb -in DREB2A_plant_orthologs.fasta -dbtype nucl -out dreb_db
import subprocess
subprocess.run([
    "blastn", "-query", "mystery_sequence_session10.fasta", "-db", "dreb_db",
    "-outfmt", "6 qseqid sseqid pident length evalue bitscore",
    "-out", "results.tsv",
], check=True)

with open("results.tsv") as f:
    for line in f:
        print(line.strip())

Remote BLAST against real NCBI (for when you have internet)

from Bio.Blast import NCBIWWW, NCBIXML

with open("my_query.fasta") as f:
    query = f.read()

result_handle = NCBIWWW.qblast("blastn", "nt", query)   # searches ALL of NCBI's nt database
blast_record = NCBIXML.read(result_handle)

for alignment in blast_record.alignments[:5]:
    for hsp in alignment.hsps:
        print(alignment.title)
        print(f"  E-value: {hsp.expect}  Identity: {hsp.identities}/{hsp.align_length}")
Remote BLAST against the full nt database can take anywhere from 30 seconds to several minutes — NCBI queues jobs. Never loop this in a tight automated batch without time.sleep() between calls, or NCBI may temporarily block your IP.
