A complete, self-contained, 4-week / 20-session course

🌱 Plant Bioinformatics with Biopython

For a tutor teaching beginners, 2 hours/day · Python basics assumed · every dataset included, offline-ready

How to use this course

Open any session's slides.html in a browser to present it. Each session folder also contains code_along.py (live-code with your class) and exercise.md (hands-on task + full answer key). All datasets used across the course live once in /data and are shared by multiple sessions.

Start with SETUP_GUIDE.md to install Python + Biopython + the small set of command-line tools (Clustal Omega, BLAST+) used in Weeks 2-3, before Session 1.

Dataset library (/data)

Every dataset is synthetic-but-biologically-realistic — built to mirror a real, named plant gene/species/study so the course works fully offline and reproducibly. Each file documents the real NCBI/TAIR record it represents and the exact search term to fetch the live version once you have normal internet access.
