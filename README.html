# Plant Bioinformatics with Biopython **A complete 4-week, 20-session hands-on course for learning plant bioinformatics with Python and Biopython.** This repository provides a **self-contained, beginner-friendly curriculum** designed to teach students how to use Python and Biopython for practical plant genomics and bioinformatics workflows. The course progresses from basic sequence manipulation to **NCBI databases, sequence alignment, BLAST, phylogenetics, molecular markers, proteins, VCFs, genome annotation, RNA-seq, GWAS, and a final plant genomics pipeline**. > 🎓 **Designed for:** Students, researchers, and beginners entering plant bioinformatics > 🐍 **Prerequisite:** Basic Python knowledge > ⏱️ **Duration:** 4 weeks / 20 sessions > 📚 **Recommended schedule:** 2 hours per session > 💻 **Mode:** Offline-ready with synthetic, biologically realistic datasets --- ## 🚀 What You Will Learn By the end of this course, you will be able to: * Work with biological sequences using **Biopython** * Read and manipulate **FASTA and GenBank** files * Perform DNA → RNA transcription and protein translation * Calculate **GC content and codon usage** * Retrieve biological data from **NCBI using Entrez** * Explore GenBank annotations and genomic features * Perform pairwise and multiple sequence alignment * Identify unknown sequences using **BLAST** * Build and interpret **phylogenetic trees** * Analyze protein sequences and identify motifs * Design simple **CAPS molecular markers** * Work with **VCF and SNP datasets** * Explore genome regions and gene annotations * Understand **Gene Ontology and functional annotation** * Perform introductory **RNA-seq expression analysis** * Understand the fundamentals of **GWAS** * Create and interpret **Manhattan plots** * Build an end-to-end plant genomics workflow --- # 📚 Course Structure ## Week 1 — Foundations **Python, Biopython & Sequence Analysis** | Session | Topic | | Modern plant science increasingly combines: **Plant Biology + Genetics + Genomics + Programming + Data Science** Bioinformatics allows researchers to move from biological questions to computational analysis: ```text Biological Question ↓ Genomic Data ↓ Computational Analysis ↓ Statistical / Biological Interpretation ↓ Research Insight ``` This course focuses specifically on examples from **plants, crops, genetics, and genomics**, making the concepts more relevant to students interested in agricultural biotechnology and plant science. --- # 🚀 Capstone Project The final session combines several concepts from the course into a miniature plant genomics workflow. Students will work through a simplified pipeline involving: ```text Sequence Data ↓ Sequence Analysis ↓ Database / Annotation ↓ Comparative Analysis ↓ Genomic Data ↓ Expression / GWAS Results ↓ Biological Interpretation ``` The goal is not simply to memorize Biopython functions, but to understand **how individual bioinformatics tools fit together into a research workflow**. --- # 📖 Recommended Background You do **not** need previous bioinformatics experience.
